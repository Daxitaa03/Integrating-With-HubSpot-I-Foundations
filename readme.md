# HubSpot Integrating With HubSpot I Practicum
 
## Project Overview
 
A Node.js and Express application that integrates with the HubSpot CRM API.
It retrieves custom object records, displays them in a Pug-rendered HTML
table, and allows users to create new records through a form.
 
## Technologies Used
 
- Node.js
- Express
- Axios
- Pug
- dotenv
- HubSpot CRM API
- Git and GitHub
 
## Custom Object
 
Object: Video Games
 
Properties:
- Name (string)
- Publisher (string)
- Price (number)
 
The custom object is associated with the Contacts object in HubSpot.
